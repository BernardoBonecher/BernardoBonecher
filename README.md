**How I work**

- **Start from the decision.** Before a dashboard or a feature, I ask which decision it should change and who makes it.
- **Measure before arguing.** Analytics (GA4, GTM, product events) and sales data come first; opinions second.
- **Build to learn.** I use Claude Code to go from spec to working prototype fast, then keep what holds up and document why.

**What I build at work** (private, company data)

Data pipelines in Python that join web analytics, ad spend and sales, and the static dashboards
the team uses to follow sales, audience and campaigns. Because they carry client and revenue data,
none of that code is public. This profile is where I build things in the open instead.

**Projects**

**[Atraso](https://github.com/BernardoBonecher/atraso)** · [live](https://bernardobonecher.github.io/atraso/)
